Ease Lab

Find an easing curve by feel instead of by numbers, then save it as a motion token.

  1. Flick the ball toward the target. How hard you throw sets a spring, and a matching cubic-bezier is fitted to it.
  2. Shape the curve by dragging the two handles, or start from a preset. Adjust duration with the slider.
  3. Pick a role: enter, exit, move or emphasis. The preview plays your curve in that job on a modal, sheet, toast, list or like button.
  4. Save and copy: name the token, save it, and copy it as JSON for Tokens Studio, CSS variables or Framer Motion.
